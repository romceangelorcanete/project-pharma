How to run / deploy (PC = Admin, Laptop = Pharmacist) - November 20, 2026

SETUP REQUIREMENTS
- Windows PC that hosts the system, with the project folder and internet access.
- Node.js with npm, XAMPP MySQL, and the XAMPP PHP CLI. `npm install` is needed once after getting the project or when dependencies change.
- Cloudflared available as `cloudflared.exe` in the project folder or installed on the PC.
- A configured MySQL database named `pharma_inventory` and `API/config.local.php` containing the local MySQL host, port, database, username, and password. Keep this local credentials file private.
- The pharmacist laptop needs only Chrome or Edge and the temporary Cloudflare URL; it does not need Node.js, PHP, XAMPP, or a local database.

NETWORK FLOW
- Laptop browser -> Cloudflare Tunnel -> Vite (port 5173) -> PHP API (127.0.0.1:8081) -> MySQL.
- `vite.config.js` allows `*.trycloudflare.com` and proxies `/api` to the local PHP API. PHP and MySQL stay bound to the PC; do not expose MySQL or phpMyAdmin through the tunnel.

FIRST-TIME DATABASE SETUP ON THE PC
1. Start MySQL in XAMPP.
2. For a fresh database, import `Database/schema.sql` using a trusted local MySQL tool. To restore a database backup, import the backup instead. Do not import a fresh schema over an existing database.
3. Confirm `API/config.local.php` points to the local `pharma_inventory` database and has the correct MySQL credentials. The PHP API reads this file; it is not included in source control.
4. If migrating an existing database that predates position titles, run `Database/add_position_title.sql` once. The SQL dump `Database/pharma_inventory.sql` already includes `position_title`.
5. From the project folder, run `npm install` once if `node_modules` is missing.

START THE SYSTEM ON THE PC
1. Start MySQL in XAMPP. Apache is not needed for normal operation; use a local database tool only when importing or checking the database.
2. In Terminal 1, run:
   ```powershell
   Set-Location D:\project-pharma
   npm run dev
   ```
   This starts Vite on port 5173 and the PHP API on 127.0.0.1:8081. If XAMPP PHP is installed somewhere else, set `PHP_CLI` to its `php.exe` path before running the command.
   To check the PHP server directly, open `http://127.0.0.1:8081/ping.php`; it should return JSON. The bare `http://127.0.0.1:8081/` may show 404 because the API directory has no root page. This ping only confirms PHP is responding; sign in to the app to check the database connection.
   To check that the Vite proxy and Cloudflare route reach PHP, open `<app-origin>/api/ping.php` (for example, `http://localhost:5173/api/ping.php` or the current Cloudflare URL followed by `/api/ping.php`).
3. In Terminal 2, run:
   ```powershell
   Set-Location D:\project-pharma
   .\cloudflared.exe tunnel --url http://localhost:5173
   ```
   If the tunnel times out, retry with `--protocol http2`.
4. Open `http://localhost:5173` on the PC and share the generated `https://<generated-id>.trycloudflare.com` URL with the pharmacist laptop.

CONNECT THE LAPTOP
- Open the current Cloudflare URL in Chrome or Edge and sign in with the pharmacist account.
- The URL changes when the tunnel restarts; send the new URL whenever that happens.

KEEP IT RUNNING AND SECURE
- Keep the PC awake and leave MySQL, `npm run dev`, and Cloudflared running while the laptop is connected. Closing any of those stops access.
- PHP listens only on `127.0.0.1:8081`; do not expose phpMyAdmin or MySQL to the internet.
- Back up the database regularly using a local database tool. On a hotspot network, if Cloudflare reports connection reset/timeouts, try another network; DNS changes are a last troubleshooting step.
